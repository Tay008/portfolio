02/04 · Security scanner

Argus

THE VERDICT
  • Finds the bug before an attacker does
  • Runs on every commit, not once a year
  • Explains the fix, not just the warning

PITCH: A one-off security audit costs more than a small team spends on tooling all year, and it is stale a week later. Argus watches every commit instead: it catches the injection, the leaked key and the outdated dependency, then hands the developer a patch inside the same pull request. Security stops being an annual event and becomes a daily habit.

  • Continuous, not annual
  • Noise filtered, real findings only
  • A fix ready in the same PR
Request a demo
STACK

Go · Tree-sitter · Semgrep rules · GitHub App · PostgreSQL

  • SAST + SCA
  • Reachability-filtered
  • SARIF output
  1. Code is parsed into a syntax tree, so findings point at real data flow instead of matching text.
  2. Taint tracking follows user input all the way to the dangerous sink — that is how an injection is proven.
  3. A reachability pass drops test-only and unreachable findings before they ever reach the developer.

03/04 · Real-time design tool

Prism

THE VERDICT
  • Everyone edits at once — no more "who has the file?"
  • Cursors, selections and edits show up live
  • Keep working when the internet drops

PITCH: Design review is still screenshots pasted into a group chat and a file called final_v7. Prism puts the whole team on one canvas: designers, engineers and clients comment exactly where the change is, and every edit lands on every screen within a frame. Fewer meetings, no lost files, no version soup.

  • One live file, never final_v7
  • Feedback pinned to the pixel
  • Works offline, syncs on reconnect
Request a demo
STACK

TypeScript · Yjs CRDT · WebSockets · WebGL · PostgreSQL

  • Multiplayer
  • Offline-first
  • 60 fps canvas
  1. CRDTs instead of locks: every edit merges, so arrival order never matters.
  2. Shape updates are batched per animation frame to hold 60 fps under load.
  3. Offline edits queue on the device and replay on reconnect without conflicts.

04/04 · Tutoring and notes

Lumen

THE VERDICT
  • The lesson and the notes stay in one place
  • Search notes by meaning, not spelling
  • Slots book and remind themselves

PITCH: Students pay for tutoring and then lose the lesson — notes scattered across WhatsApp, paper and screenshots. Lumen ties the session to the notes: book a tutor, join the lesson, and the notes, recording and flashcards are filed against that class. Tutors keep their own students, revision actually happens, and learning stops leaking out the back door.

  • Notes, sessions and flashcards linked
  • Revision scheduled for you
  • Tutors keep their own students
Request a demo
STACK

Next.js · pgvector · WebRTC · PostgreSQL · Stripe

  • Semantic search
  • Spaced repetition
  • Live sessions
  1. Notes are embedded with pgvector, so search matches meaning rather than spelling.
  2. Spaced repetition schedules each card from the student's own recall history.
  3. WebRTC carries the live session, so lesson media never touches our servers.
